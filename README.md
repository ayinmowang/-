## 快速部署说明

1. 部署平台（Vercel / Railway / 自建服务器）将 **根目录（Root Directory）** 设为 `剧本工作台`。
2. 执行构建与启动：
   ```bash
   npm install
   npm run build
   npm start
   ```
3. 首次启动后访问 `/admin` 管理后台，填入你的 API 中转站地址与 Key，拉取模型并分配给六大编剧工位即可使用。
