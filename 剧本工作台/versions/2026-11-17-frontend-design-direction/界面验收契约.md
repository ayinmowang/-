# 总编剧工作台 · 界面验收契约

## 设计方向

这是创作者反复使用的工作台。主要动作是选定创作流程、交材料、用白话说明任务，以及在总编剧提出真实待定事项时拍板。目标用户首先需要扫描当前项目、尚缺的资料和下一步动作。语气保持安静、清楚、偏编辑室；沿用纸张色、深绿、羽毛标记和现有图标。三栏是项目列表、对话、项目资料的关系，不用首页宣传内容挤走输入区。

## 可核对目标

| 范围 | 目标 |
| --- | --- |
| 首页 | 390×844、917×893、1440×900 均能看见四类入口和主要输入动作；没有未经用户选择的隐含流程 |
| 建档 | 已选择的流程只读呈现；只需项目名；仅附件也能开始；关闭和返回后草稿不丢 |
| 对话 | 本地存档与真正 AI 复述有清楚区别；已给出的集数不重复问；上传有可见进度与失败恢复 |
| 扒剧 | 明确集号自动识别；不明确时补录；已识别集号可纠正；不误触发开工 |
| 项目面板 | 桌面可快速看资料；窄屏默认不遮挡对话；长文件名换行 |
| 无障碍 | 流程选择状态可读，输入有标签，键盘焦点明显，Escape 可关弹层，减少动态效果得到尊重 |

## 内容状态

| 状态 | 触发 | 反馈与下一步 |
| --- | --- | --- |
| 加载 | 打开工作台或切换项目 | 稳定的等待提示；加载完成后回到项目或显示错误 |
| 空 | 无项目、无素材 | 显示创建或添加入口 |
| 错误 | 建档、上传、保存冲突或接口失败 | 指出失败动作，保留草稿，给出重试方式 |
| 部分信息 | 集数未定、集号缺失、创作后端未接入 | 标注待确认/待连接；允许继续补料 |
| 成功 | 建档、上传、补录、保存 | 明确成功反馈和下一步 |
| 权限 | 私有站未登录 | 提供登录入口，不呈现为已保存 |

实际渲染需在三个目标视口检查首页、建档弹层、项目对话及素材卡，并留截图。当前受私有站登录和本地预览中继限制，未完成的视口应记为“未测试”，不得伪造通过。
