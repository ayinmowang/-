# 总编剧网站 · 四类流程闭环与前后端深度优化（2026-11-17）

本版本基于《计划书_v1.md》《网站计划书.md》《项目书.md》《界面验收契约.md》《设计审查.md》及 `frontend-design-direction` 设计规范完成深度优化。原计划中已由 ayin 拍板的决定全部保留，未擅自更改。

## 本轮核心改动

1. **四类业务流程闭环与连贯性修复**
   - **原创流程（`original`）**：修复建档后因 `total === null` 被拦截无法启动的问题；支持凭一句话脑洞直接连接开启「前四层推理」，并在「停点 A」多步卡中一并拍板故事方向、开场 A/B/C、破局引擎、总集数与男女频。
   - **国外迭代国外（`foreign`）与国内迭代国外（`domestic`）**：新增 `statedLocked` 自动识别“前 N 集已锁定/定稿”，自动计算续写起始集 `start = N + 1`；右侧素材栏支持一键将附件标记为「前 N 集锁定稿（一字不动）」或「原稿素材」；国内迭代完整对接「桥段出海四级诊断」与「世界观 → 人设 → 替换要点」三道门步骤条；简化主线单增加「看得懂关（`UNDERSTOOD_GATE_REQUIRED`）」前后端双重门禁；正文阶段增加「通过，写完吧（放开后续逐集停点）」按钮与自然语言指令识别。
   - **扒剧流程（`transcribe`）**：收紧文件名集号自动识别（排除 `1-1.mp4`、微信视频等易混淆命名），未识别文件进入补录卡且支持按 `Enter` 快速保存；「快速模式 / 详细模式」严格不设默认值；交付后新增「转入国外迭代国外 / 转入国内迭代国外」主动转入按钮并自动复用已核对素材。
2. **上传、建档、草稿与历史恢复**
   - 修复打开建档弹窗时强制清空暂定项目名的 Bug；使用 `localStorage` 与 URL `?id=` 持久化保存未发草稿（已选流程、输入框文字、暂定项目名）及当前打开的项目会话，关闭弹窗或刷新页面均不丢失。
   - 首页四条快捷建议词点击后自动关联对应的创作流程方向。
3. **前后端状态、接口契约与脱敏红线**
   - 扩展进度问句识别（`isProgressQuery`），防止“现在进度咋样了”被误存入要求台账；如实返回当前阶段、步骤、批准额度及“当前暂无可靠预计时间”（严禁编造“今天”）。
   - 要求台账自动记录生效范围与版本号；支持 `client_id` 与 `action_id` 幂等去重。
   - 新增 `sanitizePayload` 递归过滤客户端响应中的模型名、线路名、token 数与系统提示词。
   - 保留原有 `STUDIO_BACKEND_URL` 生产后端 API 接入槽位，并新增 `OPENAI_API_KEY` 真实 GPT 测试通道（界面明确区分测试通道与生产后端）。
4. **桌面与移动端三视口渲染（`390×844`、`917×893`、`1440×900`）与无障碍**
   - 优化 `390×844` 首屏间距，使四类流程卡片与底部主输入区同屏完整可见。
   - 左栏项目列表补齐 `● 等你拍板` / `◐ 后台在跑` / `○ 空闲或已交付` 三态指示点；中栏顶部增加「当前停点」与「锁集范围」徽章；右栏新增「产出」标签页并按四类流程真实阶段动态推进步骤条。
   - 移动端右栏底部弹层增加背景遮罩（`.scrim`），支持 `Escape` 关闭弹窗、左栏抽屉与移动端面板；弹窗表单支持 `Enter` 提交。
