# 页面与交互审查记录

## 设计方向

产品是总编剧与创作者反复协作的工作台。首要动作是交材料、说要求并核对总编剧复述；界面保持安静、易扫描的编辑室气质。左侧找项目（通过 `● 等你拍板` / `◐ 后台在跑` / `○ 空闲或已交付` 三态点快速扫描），中间读对话与在当前停点卡片拍板，右侧查概览步骤、素材用途、阶段产出和要求台账。沿用纸张色与深绿主题、Lucide 图标、三栏响应式结构。

目标视口：`390×844`、`917×893`、`1440×900`。

## 2026-11-17 深度优化与四类流程闭环审查

本轮对照《计划书_v1.md》《网站计划书.md》《项目书.md》《界面验收契约.md》及 `frontend-design-direction` 规范，发现并修复了以下核心问题：

| 类别 | 发现的问题 | 本轮修复方案 |
| --- | --- | --- |
| 四类流程连贯性 | 原创流程建档后被 `total === null` 拦截无法点击连接推理（违反计划书“原创在停点 A 才定总集数”） | 放开原创流程连接前置集数限制，支持一句话脑洞直接启动前四层推理并在「停点 A」确认方向、开场 A/B/C、破局引擎、总集数与男女频 |
| 续写与锁定稿保护 | 首页“前 10 集已锁定，帮我续写后面”点击未关联流程；前后端未识别锁定集数，且连接后端时硬编码 `start: 1` 与 `role=source` | 新增 `statedLocked` 自动识别“前 N 集锁定/定稿”，自动计算 `start = N + 1`；右侧素材栏支持一键切换「原稿素材 / 前 N 集锁定稿（一字不动）」；导出层增加锁定稿保护声明 |
| 停点卡片与门禁 | 简化主线单未勾选「我看懂了，通过」仍可点击确认通过；多步卡缺少 ★ 推荐项快捷点选；正文缺少「通过，写完吧」放开停点动作 | 增加 `UNDERSTOOD_GATE_REQUIRED` 前后端双重门禁；为多步卡增加 `★ 推荐项` 快捷胶囊（排首位）+ 自由打字双支持；正文阶段新增「通过，写完吧（放开后续逐集停点）」按钮与自然语言指令识别 |
| 扒剧流程闭环 | `1-1.mp4` 或微信视频文件名易误识别；扒剧完成后缺少主动转入国外/国内迭代入口 | 收紧集号自动识别规则（排除 `1-1` 与长串日期名），未识别文件进补录卡且支持 Enter 保存；扒剧模式强制无默认必选；新增 `transfer_iteration` 支持主动转入国外或国内迭代并复用素材 |
| 进度询问与台账 | 进度正则过窄（问“现在进度咋样了”会误存进要求台账）；要求台账缺少生效范围与版本标注 | 扩展 `isProgressQuery` 识别各类进度追问，如实汇报阶段、步骤、额度与“暂无可靠预计时间”（严禁编造时间）；要求台账自动标注生效范围与版本号 |
| 草稿与历史恢复 | 打开建档弹窗时强制 `setTitle('')` 清空草稿；刷新页面丢失正在查看的项目与未发草稿 | 使用 `localStorage` + URL `?id=` 持久化保存首页草稿（流程、文字、暂定项目名）及当前活跃项目，关闭弹窗或刷新页面均不丢失 |
| 布局、移动端与无障碍 | `390×844` 首页四类卡片偏高易被底部输入区遮挡；移动端右栏底部弹层无遮罩且按 Escape 不关闭；左栏缺三态点；中栏缺当前停点徽章；右栏步骤条写死在第 1 步 | 紧凑化 `390×844` 首屏间距使四类入口与输入区同屏可见；移动端右栏增加 `.scrim` 遮罩与 Escape 关闭；左栏补齐 `●/◐/○` 三态点；中栏顶部增加「当前停点」与「锁集范围」徽章；右栏新增「产出」Tab 并按四类流程真实阶段动态推進步骤条 |
| API 接入槽位与脱敏红线 | 远端返回数据未过滤可能夹带的模型名/token；缺少未接生产后端时的 GPT 真实模型测试适配器 | 新增 `sanitizePayload` 递归过滤 `model/provider/route/tokens/prompt`；保留 `STUDIO_BACKEND_URL` 原有 API 槽位，并新增 `OPENAI_API_KEY` 真实 GPT 测试通道（界面明确区分测试通道与生产后端，不拿模拟结果冒充真实模型验收） |

## 实测验证结果

1. **契约与状态机自动化测试（`tests/studio.test.mjs`）**：通过（覆盖 `statedTotal`、`statedLocked`、扒剧集号防误判、进度问句识别、用户侧敏感字段过滤）。
2. **三视口实际浏览器渲染与键盘无障碍测试（Chromium Headless `390×844`、`917×893`、`1440×900`）**：
   - `1440×900`（桌面三栏）：左栏三态项目列表、中栏对话与多步卡、右栏四标签页（概览/素材/产出/要求）同屏清晰展示。
   - `917×893`（中屏双栏）：右栏默认收起不挤占对话宽度，点击顶部按钮可呼出。
   - `390×844`（手机竖屏）：首页首屏可同时看见四类流程卡片与底部主输入框；左栏抽屉与右栏底部弹层均带遮罩，支持 Escape 键关闭；长文件名自动换行不撑破容器。
3. **未测项与诚实声明**：
   - 线上私有站（`https://director-studio-ayin.ayinx.chatgpt.site/`）登录态下的多角色生产后端（`STUDIO_BACKEND_URL`）全量长耗时生成尚未在生产环境联调；本地与预览版已验证真实契约、UI 状态机与三视口渲染，未将本地预览冒充生产后端实测。
