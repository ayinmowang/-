# 总编剧工作台 · 界面验收契约（2026-11-18）

## 设计方向

这是创作者反复使用的以聊天为核心的「总编剧」工作台（Apple HIG 视觉标准 + Grok Bot 参谋式对话）。主要动作是：在极简空白对话页上传素材或聊脑洞、听取总编剧主动建议、按单步向导（一项项出现）完成确认，并在专属「实时工作台与输出」页面查看 6 大 AI 工位进度与实时剧本产出。前端移除费用审批卡，额度与并发监控统一归入 `/admin` 后台。

## 可核对目标

| 范围 | 目标 |
| --- | --- |
| 极简空白对话与动效 | 打开聊天页默认收起右侧栏与冗余横幅；总编剧回复先展示「● ● ● 正在输入…」呼吸圆点动效，再以打字机动效逐字输出，打完字后才浮现当前这一项卡片（点击气泡可跳过动效） |
| 逐项向导（一项项来） | 所有流程选项严格逐项出现（不堆叠多张表单卡）；已完成步骤自动折叠为顶部绿色 `✓` 胶囊并支持点击「重改」回退 |
| 扒剧闭环 | 支持真实上传本地视频/表格或全页拖拽；明确集号自动识别（排除 `1-1.mp4`、微信视频等易混淆名）；按「1.补集号 → 2.选快速/详细模式（无默认） → 3.锁主角人名表 → 4.校准【待人工補寫】 → 5.下载繁简双版 Word 或主动转入迭代」逐项推进 |
| 迭代与原创闭环 | 原创支持凭一句话脑洞直接启动前四层推理并在停点 A 拍板；迭代支持“前 N 集已锁定（一字不动）”续写保护；国内迭代支持出海四级诊断与世界观/人设/替换三道门；简化主线单必过「看得懂关」；正文支持「通过，写完吧」放开后续逐集停点 |
| 实时工作页面与后台 | 选定流程后可切换至「⚡ 实时工作台与输出」查看 6 工位流水线与实时剧本并一键下载；支持登录切换与 `/admin` 管理后台；全端过滤模型名、线路名、token 数与提示词原文 |
