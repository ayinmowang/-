# 总编剧网站 · 极简空白对话流、逐项向导与 Apple HIG 深度升级（2026-11-18）

本版本基于《计划书_v1.md》《网站计划书.md》《项目书.md》《界面验收契约.md》《设计审查.md》完成四类业务流程闭环（国外迭代国外、国内迭代国外、扒剧、原创），并按发起人（ayin）最新拍板要求完成了交互与视觉重构：

## 一、本轮核心升级（2026-11-18）

1. **极简空白对话页 +「正在输入…」状态 + 逐字打字机动效**
   - 聊天页默认收起右侧资料栏与顶部冗余横幅，从干净空白的画布开始对话。
   - 总编剧每次回复均先展示「`● ● ● 总编剧正在输入…`」呼吸圆点动效，随后以流式打字机动效逐字输出引导语（支持点击气泡瞬间跳过动效），打字完成后才平滑浮现当前步骤卡片。
2. **所有流程选项严格「一项项来」（单步渐进式向导）**
   - 彻底告别多张表单卡同屏堆叠：以扒剧（`transcribe`）为例，严格按 **上传视频/素材 → 第 1 项：核对与补录集号 → 第 2 项：选择快速/详细模式（无默认） → 第 3 项：锁定主角人名表并开始扒剧 → 第 4 项：【待人工補寫】镜头校准 → 第 5 项：下载繁简双版 Word 交付包或主动转入迭代** 逐项出现。
   - 每完成一项，原卡片自动折叠为顶部的绿色 `✓` 摘要胶囊，随时可点击「重改」回退修改。
   - 国外迭代、国内迭代（三道门）与原创（停点 A）的多字段阶段卡同样拆分为逐项子步骤（`1/N → N/N`）。
3. **移除前端费用审批卡 + Grok Bot 双向参谋模式**
   - 前端彻底移除费用审批卡/弹窗，不打断编剧创作心流；API 额度、并发与重试监控统一收归 `/admin` 后台。
   - 总编剧在建档前与创作中主动给出针对性改编/扒剧建议胶囊，支持一键采纳并写入要求台账。
4. **Apple HIG 毛玻璃视觉标准 + 专属「实时工作台与输出」页 + 登录与 `/admin` 后台**
   - 采用 Apple HIG（macOS Sequoia / Apple Intelligence）毛玻璃层次、弹簧过渡动效与亮暗双色主题。
   - 新增「⚡ 实时工作台与输出」视图，实时展示 6 大 AI 编剧工位流水线状态，并支持在线切换查看立项清单、故事梗概与人物小传、简体全集剧本与繁体单集剧本。
   - 新增真实本地文件上传（`<input type="file" multiple>` + 全页拖拽 + 自动读取本地视频时长与文本内容）与一键真实文件下载。
   - 新增 Workspace Passkey 登录切换弹窗与独立 `/admin` 系统管理后台。

## 二、四类业务流程与契约修复闭环

- **原创流程（`original`）**：支持凭一句话脑洞直接启动前四层推理（建档不强制先填总集数），在「停点 A」逐项拍板故事方向、开场 A/B/C、破局引擎、总集数与男女频。
- **国外迭代国外（`foreign`）与国内迭代国外（`domestic`）**：自动识别“前 N 集已锁定/定稿”（`start = N + 1`），导出时逐字保护锁定稿；国内迭代完整对接「桥段出海四级诊断」与「世界观 → 人设 → 替换要点」三道门；简化主线单强制经过「看得懂关（`UNDERSTOOD_GATE_REQUIRED`）」；正文前 3 集支持「通过，写完吧」一键放开后续逐集停点。
- **扒剧流程（`transcribe`）**：收紧文件名集号自动识别（排除 `1-1.mp4`、微信视频等易混淆命名），未识别文件进入补录卡；「快速模式 / 详细模式」严格不设默认值；交付后支持主动选择转入国外或国内迭代并自动复用素材。
- **状态持久化与脱敏红线**：`localStorage` + URL `?id=` 持久化草稿与会话；进度问句独立识别不污染要求台账；`sanitizePayload` 递归过滤模型名、线路名、token 数与提示词原文。
