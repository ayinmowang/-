## 本地命令（以 package.json 为准）

在项目根目录（本仓库中为 `剧本工作台/`）：

```bash
npm install
npm test
npm run build
npm run dev      # next dev
npm start        # next start，需先 build
```

`npm test` 实际执行：

```bash
node tests/studio.test.mjs && node tests/e2e-verify.mjs && node tests/skill-plugin-e2e.mjs && node tests/tier5-adversarial.mjs
```

第 1、2 步此前标准验收还曾使用：

```bash
npm test && node tests/commerce-migration.mjs && node tests/v3-e2e.mjs && npm run build
```

第 3 步相关测试多为独立脚本，不在上述 `npm test` 内，例如 `tests/transcribe-*.mjs`、`tests/step3-*.mjs`、`tests/step2-writeback-lock.mjs` 等，清单见《关键文档索引.md》。跑测试或在有真实数据的环境操作前，必须先备份 `.data/studio-store.json`。
