# 剧本工作台（总编剧 Story Studio）

以聊天为核心的 AI 短剧改编与原创「总编剧」工作台，完整支持《网站计划书》《项目书》《计划书_v1》拍板的四类业务流程：

1. **国外迭代国外（`foreign`）**：支持上传海外原稿与前 N 集已定稿锁定稿（`locked`），本轮从第 N+1 集续写至全剧末集（锁定稿只读注入且导出逐字保护）；依次经过总编剧复述确认 → 开始分析 → 原稿分析与待定事项多步卡 → 四项配置 → 主线与对手方案（2-3套，★推荐排首位）→ 简化主线单（必过「看得懂关」）→ 梗概人物与剧名 → 首批10集与全剧细纲 → 正文前3集逐集确认（支持「通过，写完吧」一键放开后续逐集停点）→ 自动审改汇报 → 交付 Word。
2. **国内迭代国外（`domestic`）**：在迭代流程基础上，原稿分析增加「桥段出海四级诊断」，并按 **世界观 → 人设 → 替换要点** 逐道独立确认过三道门，正文审改增加北美语感与美式幽默精修。
3. **扒剧（`transcribe`）**：接收分集视频或导出表，自动识别明确集号（模糊文件名如 `1-1.mp4`、`微信视频...mp4` 不瞎猜，进入补录卡由用户确认，且支持在素材栏修改集号），每部剧必问「快速模式 / 详细模式」（不设默认值），完成后交付繁简双版 Word 压缩包，并支持用户主动选择转入国外或国内迭代。
4. **原创（`original`）**：凭一句话脑洞即可建档并启动前四层推理（建档阶段不强制要求先填总集数），在「停点 A」一张多步卡拍板故事方向、开场 A/B/C、破局引擎、总集数与男女频，随后推进设定集、每 10 集细纲、正文前 3 集确认与整批审改交付。

## 环境变量与 API 接入槽位

- `STUDIO_BACKEND_URL` / `STUDIO_BACKEND_TOKEN`：对接多角色短剧生产后端（保留原有 `/api/projects` 全套同步槽位）。
- `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL`（可选）：未连接外部生产后端时，可启用 GPT 真实模型测试通道验证真实复述与卡片流转（界面明确标注测试通道，不以模拟数据冒充真实模型验收）。
- 安全红线：不要提交任何真实密钥、真实用户素材或数据库文件；所有面向客户端的响应与导出均自动过滤模型名、线路名、token 数与提示词原文。
