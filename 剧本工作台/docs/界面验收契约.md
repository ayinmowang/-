# 总编剧工作台 · 界面验收契约

## 设计方向

这是创作者反复使用的工作台。主要动作是选定创作流程、交材料（支持标记原稿与前 N 集锁定稿）、用白话说明任务，以及在总编剧提出真实待定事项时拍板。目标用户首先需要扫描当前项目状态（● 等你拍板 / ◐ 后台在跑 / ○ 空闲或已交付）、当前停点、尚缺的资料和下一步动作。语气保持安静、清楚、偏编辑室；沿用纸张色、深绿、羽毛标记和现有图标。三栏是项目列表、对话、项目资料的关系，不用首页宣传内容挤走输入区。

## 可核对目标

| 范围 | 目标 |
| --- | --- |
| 首页 | 390×844、917×893、1440×900 均能完整看见四类流程入口和底部主要输入动作；没有未经用户选择的隐含流程；建议词点击后自动关联对应流程 |
| 建档 | 已选择的流程只读呈现；只需项目名（支持 Enter 提交）；仅附件也能开始；关闭弹窗或刷新页面后草稿不丢 |
| 四类流程与停点 | 原创支持不填总集数即启动前四层推理并在停点 A 拍板；迭代支持识别“前 N 集已锁定”续写范围与锁定稿切换；简化主线单必过「看得懂关」；正文支持「通过，写完吧」一键放开后续逐集停点；多步卡提供 ★ 推荐项点选与自由打字 |
| 对话与进度 | 本地建档核对与真正 AI 复述有清楚区别；已给出的集数与锁定范围不重复问；有待答卡或后台运行时照常可发消息；进度询问如实返回当前阶段与无估时说明（绝不编造“今天”） |
| 扒剧 | 明确集号自动识别（排除 `1-1.mp4`、微信视频等易混淆命名）；不明确时在对话卡补录；已识别集号可在素材栏纠正；快速/详细模式无默认必选；完成后支持主动转入国外或国内迭代 |
| 项目面板 | 桌面可快速看概览（含与四类流程匹配的步骤条）、素材（支持切换原稿/锁定稿）、产出和要求台账；窄屏默认收起不遮挡对话，打开时带背景遮罩 |
| 无障碍与安全 | 流程选择状态可读（`aria-pressed`），输入有标签，键盘焦点明显，Escape 可关弹窗/抽屉/移动端面板，减少动态效果得到尊重；客户端响应与导出过滤模型名、线路名、token 数与提示词 |

## 内容状态

| 状态 | 触发 | 反馈与下一步 |
| --- | --- | --- |
| 加载 | 打开工作台或切换项目 | 稳定的等待提示；加载完成后自动恢复最近活跃项目或显示错误 |
| 空 | 无项目、无素材、无阶段产物 | 显示创建项目、添加素材或等待生成提示 |
| 错误 | 建档、上传、保存冲突（409）、门禁未过或接口失败 | 指出具体失败原因，保留输入草稿与排队文件，提供重试入口 |
| 部分信息 | 集数未定、集号缺失、扒剧模式未选、创作后端未接入 | 标注待确认／待连接（区分生产后端与 GPT 测试通道）；允许继续补料 |
| 成功 | 建档、上传、补录、锁集设置、转迭代、保存 | 明确成功 Toast 与对话内下一步指引 |
| 权限 | 私有站未登录 | 提供登录入口，不呈现为已保存 |
