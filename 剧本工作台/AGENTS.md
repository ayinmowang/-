# AGENTS.md · 剧本工作台协作规范

1. **先读文档再改代码**：动手前必须阅读《计划书_v1.md》《网站计划书.md》《项目书.md》《界面验收契约.md》《设计审查.md》。
2. **拍板决定不可擅改**：
   - 唯一聊天入口 `/`（及项目会话恢复），三栏编辑室布局（左栏项目列表、中栏对话与卡片、右栏项目资料手册）。
   - 有待答卡片或后台运行时，底部输入框照常可发文字消息，由后端判断是否为明确答卡意图或记入要求台账。
   - 扒剧模式（快速/详细）绝不设默认值；简化主线单必须过「看得懂关」才开放通过；续写锁定稿一字不动。
   - 进度答复基于真实后台快照，无可靠依据时明确说明“暂无可靠预计时间”，严禁编造“今天”。
3. **用户侧脱敏红线**：页面、接口、报错、导出文件中严禁暴露模型名、线路名、token 数、提示词或规范原文。
4. **安全与提交纪律**：严禁提交密钥、真实用户素材或数据库文件。每次版本迭代同步归档至 `剧本工作台/versions/<日期版本>/`。
