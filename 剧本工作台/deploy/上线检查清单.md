# 剧本工作台 3.0 正式上线检查清单

本清单适用于将 `work/step3-fixes-20261123`（Next.js 16.4.6）发布至生产 Linux 服务器（Node.js + Nginx + Cloudflare）。

---

## 一、部署前检查（Pre-Flight）

- [ ] **Node.js 版本**：确认 `/opt/studio-workbench-3/.runtime/node/bin/node -v` **>= `20.9.0`**（推荐 Node 22/24 LTS）。
- [ ] **系统依赖与转码**：确认系统已安装 `ffmpeg`（或保留 `node_modules/ffmpeg-static` 且 `next.config.mjs` 包含 `serverExternalPackages: ['ffmpeg-static']`）。
- [ ] **环境变量文件**：复制 [env.production.example](./env.production.example) 到 `/opt/studio-workbench-3/shared/.env` 并执行 `chmod 600`，确认关键参数：
  - `STUDIO_TRANSCRIBE_CONCURRENCY=6`
  - `STUDIO_FFMPEG_CONCURRENCY=3`
  - `STUDIO_VIDEO_COMPRESS_THRESHOLD_MB=3`
  - `STUDIO_LLM_TIMEOUT_MS=120000`
  - **禁止**在生产 `.env` 中设置 `STUDIO_LLM_FIXTURE=1`。
- [ ] **单进程约束**：确认 `systemd` 使用 [studio-workbench.service](./studio-workbench.service) 运行**单进程 Node.js**（切勿使用 PM2 cluster 多进程模式，否则内存锁与异步任务注册表会分裂）。
- [ ] **Nginx 反向代理**：对照 [nginx-studio-workbench.conf](./nginx-studio-workbench.conf) 确认已配置：
  - `client_max_body_size 256m;`
  - `proxy_request_buffering off;`（避免大视频上传阻塞）
  - `proxy_buffering off;`（避免 SSE 流式进度被缓冲）
  - `proxy_read_timeout 180s;`
  - `nginx -t && systemctl reload nginx` 通过。
- [ ] **权限隔离**：确认 `.private-transcribe-evidence/` 目录权限为 `0700`，Nginx **严禁**静态暴露 `.data/` 或 `.private-transcribe-evidence/`。

## 三、上线后管理后台配置（`/admin`）

- [ ] 使用管理员账号登录 `/admin`（首次上线建议立即修改默认管理员密码与专属 Key）。
- [ ] 在「API 渠道池」中填入线上中转站地址（如 `https://code28.ccwu.cc/v1`）与正式 API Key，并点击连通性测试。
- [ ] 核对「工位路由」：默认已配置为 **`gemini-4-hydrogen`（主）→ `gemini-3.8-flash`（备援 1）→ `gemini-4-argon`（备援 2）**（全部在白名单内，且支持 524/超时自动切备援）。
- [ ] 核对「套餐与邀请码」配置，以及是否开启「邀请码自助注册（`allowInviteRegistration`）」。
- [ ] 如需同步线上既有扒剧存稿为 V7.2 格式，先执行 `node scripts/sync-transcribe-format-v72.mjs --dry-run` 核对无误后再 `--apply`。

## 四、上线后 5 分钟冒烟验收

- [ ] **登录与权限**：`/login` 登录正常；普通创作者访问 `/api/admin` 返回 `401/403 FORBIDDEN_ADMIN_ONLY`。
- [ ] **扒剧闭环（`/breakdown`）**：上传 1 个 `>9 MB` MP4 → 点击开始扒剧 → 请求 `<1s` 返回并进入轮询 → 1 分钟内交付 V7.2 简体正文（无繁体硬字幕残留）→ 下载 `.docx` 正常 → 一键转入国外迭代且下载目标 MP4 字节数与原片一致。
- [ ] **三栏创作闭环（`/studio`）**：新建原创/国外/国内项目 → 右栏 4 步进度卡一键生成大纲/人物/分集正文 → 锁定第 1 集后改写返回 403 → 点击「导出 Word」正常。
- [ ] **商业化闭环**：`/purchase` 提交测试订单 → `/orders` 四档筛选全部 HTTP 200 → `/admin` 确认入账 → `/subscriptions` 显示生效订阅与历史记录 → `/usage` 查看用量并导出 CSV（创作者端 0 模型名/密钥泄露）。

---

## 五、快速回滚方案

1. 切换软链回上一发布目录：`ln -sfn /opt/studio-workbench-3/releases/<上一版本> /opt/studio-workbench-3/current`
2. 若需恢复数据，从 `/opt/studio-workbench-3/backups/studio-store.<时间戳>.json` 拷回 `/opt/studio-workbench-3/shared/.data/studio-store.json`
3. 重启服务：`systemctl restart studio-workbench.service`
